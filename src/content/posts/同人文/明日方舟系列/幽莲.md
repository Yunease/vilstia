# 客观履历

身份不明的拉特兰少女，似乎因为源石病而患有精神类疾病。外出野餐的铃兰和桃金娘在悬崖下发现了奄奄一息的幽莲，在凯尔希和其他医疗干员认为恐怕无力回天时，幽莲凭借自身出色的自愈能力和坚强的意志力撑了过去，并在极短的时间内完全康复。

在测试作战的过程中展现出了令人头痛的性格，个人作战能力优秀却不能独当一面，需要与其他干员配合，而本人的心思却似乎更在于自己的战术规划。

 

# 临床诊断分析

造影检测结果显示，该干员体内脏器轮廓模糊，可见异常阴影，循环系统内源石颗粒检测异常，具有明确的矿石病感染现象，现阶段可确认为矿石病感染者。

 

【体细胞与源石融合率】21%

患者幽莲体表多发结晶，病灶遍布全身。患者病情直到现在也没有获得妥善的控制，本人却完全不在意自己的病情。

 

【血液源石结晶密度】0.58u/L

患者幽莲内循环结晶密度呈现缓慢增加态势，正在以医疗组核发的第二批治疗方案进行治疗。凯尔希批注：即便如此也不能对病情掉以轻心，一定要严格实施定期监测。

 

# 档案资料一：

幽莲是一个非常胆小，乖巧的孩子，平时总是在宿舍内看各种深奥晦涩的书。明明本应该是听话懂事的孩子，却在战斗上有着难以理喻的固执。也许是很难相信别人，她总是竭尽全力去践行自己的想法。不过这并不代表她的团队作战能力不足，她经常在其他干员最需要的地方发起致命一击，在敌军疏忽的刹那打乱他们的进攻节奏，并使用自己的源石技艺在不知不觉中让他们陷入无法逃离的幻境之中。

Tips：不要在幽莲面前调戏铃兰或着桃金娘，否则可能会被没收了武器的幽莲当作欺负好朋友而痛打一顿。

没有人知道她为什么对于友情如此执着，也没有人清楚她对于朋友的定义，只知道她会为了朋友而堵上一切——哪怕是生命。铃兰非常喜欢这个会躲在自己身后抱着尾巴的孩子，而幽莲也乐意充当铃兰的保镖一样的角色，两人在共同完成一些特殊任务的时候往往会取得意料之外的出色效果。

关于幽莲的过去，她似乎只对铃兰和桃金娘说起过，不过要是去问她们的话也会以“好朋友的秘密”为理由而回绝。但从铃兰和桃金娘的表情里大概可以隐隐约约的猜到，那绝不是什么开心的历史。

也许有一天，当幽莲能够坦露出心声的时候，能够被依赖的朋友就不仅仅只是铃兰和桃金娘了吧。

 

# 档案资料二：

“我抓不住已经逝去的一切，我没有办法再接受他们的离开了。”

“我讨厌对于我来说重要的一切的事物变成泡影……”

干员幽莲似乎对于一些事情有很强的执念，她是一个很敏感的人，幸好心思细腻的铃兰和活泼开朗的桃金娘足够照顾她的情绪了。有时这种执念也并非坏事，在战场上表露出来的判断力和冷酷不亚于拥有丰富作战经验的特种干员，她会在一瞬间把敌人撕成碎片，抑或是令其陷入幻觉中被痛苦折磨。这样扭曲的心理引起了其他干员的注意——阿米娅曾尝试过与幽莲沟通，但对方无论如何都保持着戒备心，到头来也没有取得什么进展。

不过在平时，干员幽莲还是一位富有同情心的善良孩子，她几乎会无条件的答应别人的要求，在闲暇的时候也会做浇浇花之类的事情，甚至会抱着跌落鸟巢的幼鸟爬上树送回去。

“博士…您是很特殊的人…对不起…我还是没办法信任您…善良并不能分给所有人…我知道…”

幽莲说出来东西似乎只占据想的东西的很少一部分，她的内心世界无从窥探，也无法从只言片语中猜想她的心思——或许她本来就没有想要别人知道这些吧。

 

# 档案资料三：

倒塌的房屋，焦如黑炭的枯萎花朵，分崩离析的大地。

被火焰吞噬的泪痕，绝望哀婉的叹息，一颗破碎的心。

无力回天的祈望，孤独脆弱的恸哭，颤抖无助的惊恐。

“我必须要阻止什么才可以…现在…还不算晚…”

于是她不再沉睡，张开精神领域开始给予命运最后的反击。

某一位不小心走入幽莲的幻境的干员曾看到了这样的风景，那之后她的精神状况变得极不稳定，被迫调回了后勤组。除去对于幽莲本人的精神状态需要高度注意以外，也要注意保护可能与幽莲有接触的干员的精神状态，幽莲似乎无法控制自己精神爆发的时间和地点，尽管她通常会把自己锁起来度过意识朦胧的时间，但不排除有干员在不知情的情况下陷入精神崩坏的状态中。现有的观察资料大概可以评估干员幽莲下次失去意识的大概时间，尽管如此还是应当给予高度重视。

事后陷入昏厥的幽莲会露出这个年龄段的孩童有的天真表情，也许只有在彻底宣泄了自己的混乱之后，才会获得短暂安逸的休息时间吧——尽管这段时间是无意识的，但对于幽莲来说也是不可多得的宝物吧。醒来之后，一切照常，幽莲风轻云淡的样子仿佛什么也没发生一般。希望最好是这样，欢迎回到由自己支配意识的现实世界，幽莲小姐。

 

# 档案资料四：

也许她的匕首不是最锋利的，却可以悄无声息的刺入谁人的梦乡之中。在他人精神松懈的时候才可以轻易瓦解对方的防御——至少幽莲也许是这么认为的。

“很抱歉夺走你的幻想…但我必须这么做才可以…”

虽然幽莲并不会主动的接触某一个特定的干员，但她似乎对每个人都有观察。据说，她有一个小本本专门用来记录一些乱七八糟的琐事，譬如极境又耍了几次帅，缪尔塞斯偷偷在日记本上写了什么，等等等等……幽莲似乎知道很多不太容易被知道的事情，难道这也是她的精神力特性让她窥探到的信息？我们不得而知，况且这个小本本是否存在都是需要怀疑的事情。

幽莲可能并不像她表现出来的这么冷漠，她很多次地救下了差点摔倒的卡缇，如果说她对周围的事物毫不关心而在一瞬间伸出援手，似乎也不太可能。幽莲的温柔超乎大家的想象，她会在失眠的夜晚驱散其他人的噩梦，轻轻的安抚着他人，送上柔和的祝福。藏匿在暗处的监控设备存在的事情幽莲大概并不知情，但我们相信就算她察觉到了，性格善良的她也会继续在大家不知道的地方悄悄的治愈着其他人吧。至于为什么把自己的温柔表现得如此隐晦…似乎，她也有自己的考虑吧。

# 晋升记录

 

大多时候，幽莲似乎都没有用全力在作战，据她本人懒洋洋的回应说，是担心暴露过多的精神力影响到其他干员，虽然她有一个人处理复杂局面的信心就是了。

作为一个小孩子，幽莲却有着不太好的嗜好——喜欢喝酒，尤其喜欢羽毛笔调的酒，而且还喜欢烈酒。

酒精会麻痹神经，以至于让人产生不可控意识之外的幻觉，也许是因为这个原因她才如此依赖酒精吧。除此之外，幽莲还喜欢自己调酒，虽然…只有她自己能喝得下去就是了，她的口味如此独特，相当罕见。

在熟悉了罗德岛的环境之后，幽莲会出没在人迹罕至的角落里。有时候回去水族馆看热带鱼，有时候会去植物园赏花……她的兴趣是如此隐蔽而广泛。令人意外的是，她不介意向别人分享自己的爱好。
