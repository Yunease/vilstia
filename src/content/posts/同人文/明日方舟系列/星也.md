# 客观履历

星也，经由伺夜引荐加入，现作为罗德岛常驻干员。经过工程部面试合格，现协助工程部进行装备改造和图纸设计，鉴于其特殊的源石技艺，也会参与一些作战活动，担任支援协助和辅助控制的责任，必要时也能挥动武器逼退敌人。

在加入罗德岛前，星也和其扶养人从事装备锻造的工作，不仅熟练打下手的工作，也有相当丰富的工作经验，甚至无师自通了部分材料学知识。



# 临床诊断分析

造影检测结果显示，该干员体内脏器轮廓模糊，可见异常阴影，循环系统内源石颗粒检测异常，有矿石病感染迹象，现阶段可确认为矿石病感染者。

 

【体细胞与源石融合率】6%

星也的矿石病比预想中严重，也许是在叙拉古流离时加深的。在右手臂和大腿根部分布有明显的源石结晶。经过诊断治疗后，病情有明显改善。

 

【血液源石结晶密度】0.21u/L

矿石病灶得到一定程度的控制，但需要特殊注意其家族遗传性的幻觉和精神缺陷，在极端情况下，使用不受控制的源石技艺可能会加深症状。

麻烦的病人怎么越来越多了。——华法林

罗德岛的责任也包括关注干员的其他症状，请端正作为医生的态度。——凯尔希

 

值得注意的是，逻各斯的咒言竟然会有意料之外的镇定作用，尽管暂时还不知道运作原理，但通过长期的治疗观察，确实能在一定程度缓解患者的症状。

 

# 档案资料一：

叙拉古的雨在回忆里终年连绵，像剪不断的思绪，纠缠成糟糕的线团。

过早离世的亲人，让她流浪了相当长的时间。我们无从知晓一个无家可归的孩子是如何在叙拉古这样的地方生活下去的。还好她遇到了“爷爷”。爷爷并不是她的亲戚，只是在星也某次被矿石病折磨晕在垃圾堆中，捡她回家的人罢了。虽然和爷爷的生活并不富足，但总算是回到了有爱的原野里，使星也接受了一定程度的教育。

爷爷是小镇上颇有名气的铁匠，平日里承包一些简单的铁器修理或制造的工作，不过和他平易近人的外表完全不符的是，他本人也是位技艺高超的武器锻造师（他曾说过自己已经老得挥不动这些笨重的东西，也许他年轻的时候也有过叱咤风云的时光吧），据说叙拉古的某个家族帮派经常从这里订购一些武器。出于此原因，星也在很小的时候就熟悉锻造和武器。

直至，连最爱她的爷爷也离世。下葬时，人们都说是自然死亡，节哀顺变。可葬礼后排那些打着黑伞的人，分明是在得意，嘲弄黑手另在。叙拉古的云层从来没投下多少阳光，压抑的种子开始疯长。

那一定是一段不愿回忆起的生活，不过和星也表现出来的样子完全相反——她甚至有些活泼地过头了，很让人担心是不是故作坚强的样子。但这种表面上的乐天派却让她能够很好地和所有人相处，至少在工程部，她很受欢迎。

 

# 档案资料二：

星也小姐的源石技艺相当特殊，甚至翻阅文献都无法找到相近的症状。她拥有远超年龄的冷静和警惕，还有城府。如果您在转角碰面打招呼的时候被无视掉了，第二天又被她乐乐呵呵地搭话，请不用在意，她对谁都是这样。

有时候她会和自己说话，嘀嘀咕咕的，有时候会突然爆发出难以追溯的情绪，考虑到这个原因，阿米娅专门给她分配了隔音的单人宿舍。

她会对着镜子笑，然后哭，时而像喜剧演员那样歌唱，时而沉郁，坐在宿舍的床上一言不发。经过几次治疗，大概确认了这种离奇的症状并不是矿石病的衍生病，而是与生俱来的遗传病，星也小姐在回忆中，似乎家人也曾有相似的样子。当然，也存在环境的诱发因素，亲人和扶养人的离世对任何人来说都是极其痛苦的事情，叙拉古的阴云是加重苦闷的温床。

源石技艺石诅咒伴随的馈赠，如此罕见的病症赋予了星也超乎想象的力量，只需要静心冥想，就能闭眼看到另一个自己，另一个温柔地包容着她一切的自己，在情绪亢奋时，镜中的星也会跨越现实的界限。虽然到目前为止，镜中世界并没有对现实有太多影响，但仍然得到了罗德岛的重视，谁都无法确保另一个世界里潜藏着什么样的存在，对星也小姐精神状态的关注时必要的。

不过好像也没有想象中严重，星也那种活泼外向的性格十分讨喜，希望这份来之不易的友谊能够帮助她维系自我的稳定。

 

# 档案资料三：

唯一值得信赖的爷爷离世后，星也就接替了武器铺的工作。她的手艺不如爷爷精湛，但常规的需求早已熟能生巧，也能够维系这样的生活。

但她不愿意，也不接受，她对压抑的叙拉古没什么感情，对冷漠的叙拉古人没什么感情。夺走她的亲人，让她踏上流浪的路，在饥寒交迫的夜晚看见富丽堂皇的宴会中虚妄的舞蹈。星也没有恨，也没有爱，这片土地没有养育她的恩情，只有填写档案时平静地写下出生地，她只是不停徘徊的边缘人物。

无视掉帮派的威胁，星也关掉武器铺，带走爷爷留给她唯一的遗产——那把有着浅蓝色雕琢花纹的镰刀，再次踏上流浪。命运总会眷顾每一个人，哪怕只有一两次。没多久她就遇到了伺夜，在发动作战的鸣雷前夕，伺夜需要更多的力量来打破叙拉古的黑暗，他，斥罪，还有德克萨斯，这点人数还是不够用，可偌大的叙拉古，还有谁能信任，能够托付呢？敌视腐朽帮派，背景干干净净的星也就成为了最好的人选。

起初，星也并不愿意相信伺夜，伺夜也没有强迫她，只告诉她“你想要做的，和我们正在做的，是同一件事。”或许是这份坦诚打动了她，或许是星也真的无处可归了，她最终接受了伺夜的邀请，成为行动中最为特殊的行动人员——是的，她根本没有任何履历可以被调查，连爷爷留下的小屋也毁于一场爆炸中。预想中的计划进行的非常顺利，伺夜成功了，星也发挥的作用比他想象中还要大。叙拉古的阴霾淡了些，伺夜又要面对新的挑战，各种杂乱的事情多的脱不开身，但他还是信守诺言，给予了星也应得的报酬——以罗德岛特派干员的身份，引荐星也加入罗德岛，获得治疗矿石病的机会。

“这个地方能找到你需要的东西。”

“好，我明白了。”

“遇到什么问题可以报我的名字，但我能帮的有限，暂时无法脱身。”

“如果想回到叙拉古的话，这里也随时有你的位置。”

“谢谢，这就免了。”

于是，星也告别故土，前往新的世界。

她有点忐忑，也有点好奇。不管怎么样，应该没有地方能比叙拉古还令人失望吧。

 

# 档案资料四：

尽管星也的遭遇令人动容，她本身的社交能力却强的吓人，没几天就见她在羽毛笔的调酒台听妮芙讲故事了，至于她是怎么融入进去的，我们还是不要太多过问为好。

当然，和她相处最多的，则是辅助医师身份的逻各斯。由于她特殊的症状，每个星期都要有两天专门坐着接受约束治疗。我们观察到星也小姐似乎对逻各斯干员有着非同寻常的感情，至少逻各斯不会单独出现在甜品店，星也也不会一个人尝试旋转座椅赛车比赛。

天晴的时候，能看见逻各斯早早出现在舰船的甲板上，不要去打扰，因为他在等星也小姐，接下来是治疗时间。他向华法林和凯尔希申请，争取到了可以在室外治疗的权力，这样星也小姐就不用躺在治疗室，无聊地盯着泛白的天花板看了。

因为这个变动，两人之间还发生过一些小插曲。

妮芙得知星也可以离开治疗室了，于是兴致冲冲地找她说话，起初逻各斯也不介意，但后面来的人有点多的过头了，围在星也后面一小圈，逻各斯一点都不喜欢被这么多目光瞩目的感觉，也不喜欢这种治疗时间有其他人介入，于是重新向凯尔希递交申请，现在，星也的治疗时间只属于她的辅助医师。

时候妮芙给星也写了封道歉信，不过星也一点不介意，只是“呵呵呵”地对着逻各斯微笑。

 

在其他时候，逻各斯也会陪伴星也，按他的话说算是“辅助医师对患者的关照”，不过两人默契的对视已经足够说明一切。只不过，逻各斯偶尔也会见证一些不那么开心的经历，星也是如此坚强，两人在每一次错愕中重新塑造对彼此的认知。。

“分析完毕，你是想听温柔一点的，还是残酷一点的呢。”

华法林低头看着检测报告，等待着星也的答复。

“要不先…”  “请直说吧，我等待真相已经很久了。”

星也打断逻各斯，却打断不了他的担忧。

“您是镜狐，老实说，这三个字出来的时候我也不敢相信。不过，结合你的症状，这倒是很有道理，譬如你的失眠，幻觉，还有焦虑和那个说不清楚的镜中自我，都是镜狐一族的特有的病症。”

“那…星也她，有什么办法吗？”

“无药可救，镜狐生来如此，也正因为这种缠身的病症，自古就被视为遭诅的象征，镜狐一族一直在流浪，导致他们分布广泛又稀少。顺带一提，在伺夜传回的报告里，叙拉古已经没有镜狐了。星也小姐，您也许是最后的镜狐。”

“我知道了。”

谢绝了逻各斯的好意，星也独自也能承受这份命运的重量。

仅仅是因为，来到罗德岛的这段时光，与干员们的邂逅，让星也已经不再是过去那个孱弱的自己了。

 

# 晋升记录：

四处奔波的生活使她多次辗转，在罗德岛的这些日子，放在她的生命里，会占有多大的比重呢？

阿米娅希望星也能把罗德岛真正当作家，但连她自己也知道这样的事情根本不现实。生性敏感的镜狐很难对土地和人产生感情，那些或是美好或是肮脏的东西，在镜中，在梦中，星也已经见过太多太多了。

她没有理由。不过正因如此，她需要理由。

能够和逻各斯并排在甲板上吹着来自晚霞的风，大概是星也此前也从未经历过的吧。

因为…你看，她的眼睛如此美丽，如此真挚，这种景象永远不会出现在镜中。

叙拉古的日子，就告一段落吧。晚安，爷爷，我现在很好。

# 模组故事——雨水会回溯至同一片天空

一张特别行动的伪造身份证件，由莱昂图索委托定制，用于在特别行动中获得接应，出入部分行动作战区域。

大概是准备得仓促，这样身份证件有不少疏漏，连我原来的名字都印错了——“幕”。人们常说，真真假假相互杂糅，这张身份证件至少一大半的信息都是真的。可笑的是，即便像我和爷爷这样曾经居有定所的人，只要身份足够贫贱，在叙拉古的最臭名昭著的血债账本上，甚至连自己的名字都留不下。也正因如此，行动进行的比预想中顺利太多，几个呆头呆脑的门卫一边查看着这张证件，一边对比账本，结果半天看不出什么问题，只好向我表达歉意并放人通行，这副光景着实令人忍不住笑。

行动成功后，我保留了这张证件，也许只是因为，在过去，我和爷爷甚至没有一张属于自己的身份铭牌。莱昂图索曾提出重新造一个工艺更精良的铭牌，顺便把错别字也一起修正了，不过我没打算要。伪造的东西，制作的再美丽，又有什么用呢？我留着它，只是为了提醒自己，星也也不过是一个好听的代号而已。

和逻各斯一起离开华法林的诊断室的那天，比想象中还要轻松。生而有之的一切皆是我的构成，不论是那些幻觉，还是超越幻觉的另一个自己。得知此事后，有位羽蛇同我长谈，她也是一族的末裔。我没那么多的负担，镜狐没有带给我什么，也就谈何义务去传承。高雅的羽蛇啊，你的痛苦与挣扎又是什么呢，你也在凝视水面之下的自我吗？

泰拉没有一寸乐土，但和叙拉古相比，罗德岛还是好得多。同样是沉闷的雨夜，叙拉古只有无穷无尽的黑，黑得发瘆，逼你遁入梦乡。而在罗德岛，至少会发给我一张正儿八经的、没写错字的工牌，还有同伴，女妖，萨卡兹、佩洛、菲林，他们会围绕着我，一直熬夜讲着有趣的见闻。

萨尔贡雨林的水珠也会随着季风吹到萨米的冻土上，湿热的蒸汽和千年不化的坚冰并无区别，我们终归要回到同一个地方去。至于原先那张伪证，就夹进工牌的背面吧，它也该翻篇了。
