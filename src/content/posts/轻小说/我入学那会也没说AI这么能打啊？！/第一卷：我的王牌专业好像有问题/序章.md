# 不会成为提示词工程师！

名牌高校倾尽全力培养出的，具备新时代信息素养与目光远见的，卓越计算机技术青年工程师。

看起来就像为了吹嘘而写进简历的，类似“精通C++编程”又或是“TypeScript全栈开发”的形容，对于王悠真来说并不算是浮夸的描述。确切的说，他应该算得上通常意义上的极客 (Geek) ，按照入学时往届优秀学长那漫长而陈垦——又或许算是敷衍的演讲，这种大学毕业的 JAVA 程序员，理应是能够轻松得到月收过万的工作，并且走上完美人生的。

本来应该是这样的。

然而，这已经是王悠真“灵活就业”的第三个月了。尽管他在大学时就因为经常做外包工作而攒下了一个小金库，但若是一直负担着这样无所事事的生活，大概也支撑不了多久吧？

况且，母亲打过来的电话也不能不接，如果再找不到工作的话，大概会变得很难收场，到时候恐怕会上演串门被赶出去的场景。曾几何时，王悠真还是母亲在楼下和人闲谈时，会被人当作“别人家的孩子”而推出来夸赞的优等生。

本来应该是这样的。

就算费尽心思搭建了好几个工作流让不同的 AI 换着来修改简历，又或者几乎如同拜托玄学一样安装各种简历编辑 AI Skills ，王悠真辛苦投递的一百份简历连返回报错都没有，仅有的一家初创公司愿意让他来面试，可是，那也不是正儿八经的 JAVA 开发，而是给公司本地部署的小模型写提示词，这种工作简直是亵渎——王悠真反正是这样想的。况且，仅仅是因为允许使用 AI 辅助，HR 就要以没有技术门槛为由，把基本薪资再往下压一点。

闹了半天还不如职高表哥打游戏娱乐陪玩呢，起码人家每天玩的很开心。

尽管心里这样想，王悠真也没打算放弃寻找一份专业对口的工作。不过总是宅在家里也不行，要是成为和社会脱节的“待业青年”，那可就有受不完的麻烦了。

王悠真答应了叔叔要带着表弟去看培训班。

或许是中年人特有的职场焦虑，明明是文职的叔叔依然加入了轰轰烈烈的 AI 大家庭，前两天还在研究怎么安装 DeepSeek，可惜弄了半天还是不幸安装成了盗版的电脑 AI 助手。王悠真都有些佩服了，这年头能从一众官方渠道里找到盗版链接可不是一件容易的事情。

“编程和 AI 都要从娃娃抓起。”

于是叔叔这样说道，表弟也就倒霉地多加了一门额外的课外辅导班，本就紧张的周末更加所剩无几。少儿编程，赢在起跑线？反正王悠真绝不信得过这种东西，能教个 Hello World 或是 for 循环什么的，都算得上有良心的辅导机构了。

况且这些内容放在视频网站，也不过是几分钟的内容——忘记说了，稍微麻烦一点的环境配置，也早就已经焊死在辅导机构的电脑上了。

换而言之，一整个课时大约四十多分钟，也只不过敲下了短短几行的代码，大概还有不少人整节课都在和中文字符和缩进做斗争。

若是换成没良心，纯就是利用当下的焦虑浪潮来骗钱的辅导机构，可能连真正的代码都不会让人写。

王悠真对这种东西没什么好感，他觉得受到过高等教育的计算机系学生，应该都对之嗤之以鼻吧。

不过，这些事情也不需要他操心，辅导班是叔叔找好的，王悠真要做的，只不过是把表弟从家门口，送到辅导班，然后等下课再送回去。顺便，叔叔想让他看看这个辅导班靠谱不靠谱，若是说真心话，那大概会是“肯定靠不住”之类的，但是王悠真也懒得给叔叔解释，反正他也听不懂。

况且，他对这个小鬼没什么好感。

王悠真的表弟王博文并不算那种惹人讨厌的“熊孩子”，却也绝对让人喜欢不起来。不过，仅仅是把人送过去上课，应该不会产生太多需要纠缠的麻烦吧……王悠真如此想到。

“喂，小鬼，该走了。”

他面无表情地看着正在收拾书包的表弟，此时的博文正焦头烂额地收拾着东西——不过大多也都是些准备上课吃的零食，手机还有充电器之类的。

这种少儿编程本来就不需要纸笔，空荡荡的书包让那种来自学生的服从性彻底荡然无存，上这种课就是玩去的，王博文一直这样认为。

“哥！不要再叫我小鬼了，我现在已经五年级了，就算是化简运算那种算术题也不在话下！”

嘴上这样说着，不过王博文还是一副嬉皮笑脸的样子。或许是因为之前打手机游戏总是输给表弟，王悠真只好板着脸，装出很严肃的样子。

“快点给我走啦！小心我揍你。”

“OK呀老弟，我这就来好吧。压力！”

“谁是你老弟了！压力又是什么鬼东西！”

把调皮的表弟扭送到少儿编程辅导班可不是件容易的事情，宛如麻雀一样的，一路上小嘴就没停过。

“哥，虽然你编程比我厉害，但是你打火影忍者未必有我强。不吃压力好吧，这块你还得练。”

“老弟你也不行啊，我妈说你毕业好久了都没工作，要不我来带你打火影忍者吧，咱俩一起做主播，搞点单挑剧本，我让我们班同学都关注你。”

好在王悠真并没有太把这小鬼当回事，把人送到位置，玩一个小时手机，再把人领回去，就算任务完成。至于回去之后怎么给叔叔说，等会儿问问豆包就行了——我现在立刻就用最客观，最理性，最公正，最不拐弯抹角的方式告诉你，少儿编程其实没什么用。

拽着表弟的衣领，眼下这个装修敞亮的店面，便是未来方舟少儿编程科技中心——简称方舟编程。

尽管王悠真还是坚持认为，这种地方不过是忽悠外行家长的地方，现在也被这种精致的装修有些镇住了，好像还真是这么回事似的，一般家长看到一排排书架和简约风格的桌椅，还有被小型聚光灯照射着的 Logo ，大概也会觉得这里真的是把孩子送进去就能成才的地方。

不远处站得笔直的辅导班老师与王悠真目光交汇，对方原本的笑容顷刻间就凝固掉了，就像偷懒的程序员忘记删除的调试 Sleep 函数触发了，那笑容僵硬的卡住，原本那副成功人士的自信也灰飞烟灭了。

“王，王悠真？”

眼前身材高挑而有些精致打扮的成熟男性，却用着王悠真十分熟悉的声音在说话。

“社，社长？您，您怎么……”
