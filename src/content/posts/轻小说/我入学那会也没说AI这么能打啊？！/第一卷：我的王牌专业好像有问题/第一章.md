# 极客不会相信统计学

王悠真咽下一口唾沫，在绝对不会信任的少儿编程机构，遇到了绝对信任的 ACM ( 国际大学生程序设计竞赛 ) 社团的前任社长。带领懵懂学弟学妹们一路夺得国赛金奖，披荆斩棘的前社长——金宇霖。尽管他在算法以外的领域表现平平，但作为社长还是担起了应有的责任，即便后来有了新的继任者，他的名字也从未离开过社员的嘴。

“如果是前社长的话，大概这种题会拆开解吧，先暴力猜几个特殊解，然后再贪心求一部分，若是贪心策略超时了，剩下的再用动态规划-剪枝策略算出来。”

不过，比王悠真更加震惊的，便是表情已经无法归类的金宇霖了。

“王悠真？真是你啊，你怎么来这里了？”

回想起庆祝社长毕业而聚餐的傍晚，意气风发的金宇霖正规划着接下来的方向——大厂实习 -> 基层程序 -> 算法研究与设计岗。彼时的王悠真和其他社员并不认为这是空中楼阁。

方舟编程，是大厂吗？

王悠真皱着眉头开始检索，也许，也许这家名不见经传的辅导机构，也是某个大厂最新搞出来的教育方向的新部门，而早就升为高管、受到所有人信任的社长，接下了方舟编程的孵化与拓荒任务。就算使用付费第三方的 Web Search API，也绝不可能搜到这种东西，况且王悠真的头脑也连不上网。

“现在工作是不好找啊……没想到你也会考虑这个。”

难道说，这一切，社长早就知道了？王悠真摇摇头。

金宇霖有些苦笑着，让角落里一个低头刷手机的老师领走了王博文，先把这孩子拉去试试课，王博文似乎并不在意，再临进教室的时候，突然转头大喊了一句：

“OK呀老弟，等会儿见，我也是开始抗压了好吧。”

不过这声音对于专门隔音设计的墙来说，就显得有些无力了。

“虽然你也选择少儿编程机构啥的倒也算是意料之内，不过没想到居然是同一家……”

“眼下来方舟编程报班的家长倒是越来越多了，薪资待遇什么的都还不错，你要是想来的话，也能争取一下，前两天面的几个老板都不太满意，虽然你学的方向不是 Python ，但是讲这种东西应该也不困难吧。”

等等！社长，您是不是搞错了什么啊！王悠真的脑子在满载空转——他怎么可能选择来这种少儿编程机构来上班啊！

“社，社长，好久不见啊……其实我今天，就是来送表弟上课，也没啥别的意思，毕竟是家里安排的，反正闲着也是闲着……”

几乎是说出后才意识到后悔的，王悠真不经意间瞪大了眼睛，糟了，怎么把自己闲着的事情说出去了。

本来还可以圆场，反正今天是周末，只要说是工作不忙什么的，大约也能搪塞过去。

可惜，现实似乎并不如此。

要怪就怪自己下意识脱口而出好了……王悠真已经不知道该如何开口了。虽然在少儿编程机构当老师，并不是什么光彩的事情，但是和“灵活就业”相比，那还算是有份工作了，起码包吃包住，工资……好像也不错。

金宇霖最终还是决定留够双方的面子——尽管这种东西和事实真相比起来一毛不值，可眼下也是两人仅有的秘密了。他低头看了看手腕上的表，似乎在确认时间，又好像是在逃避目光。

“等下还有节课，没办法奉陪了。你可以去那边坐着休息，或者……如果你对方舟编程感兴趣，希雅就在前台，你要不问问她吧，虽然她现在也只是实习，不过也算熟悉过环境了，有什么问题都可以去问她。”

“……”

金宇霖似乎有些疲倦，或许是接下来还有课程，他整理了一下衣领，然后阔步向着一个小课班教室走去。

王悠真彻底震惊了，浑身无力地瘫痪在椅子上，就好像目睹了一场原子弹的爆炸，计算机专业能混得这么差，这种念头从未如此强烈过。

王悠真并不认为自己学艺不精，尽管他和那些“全栈开发”和“前后端通吃”的怪物比起来，技能确实没那么丰富，但若是寻常的 JAVA 开发，上到 Spring Boot 框架搭建，下到 MySQL 数据库设计，甚至简单的分布式服务器配置，他也能够轻松完成。

王悠真并不是那种从 GitHub 上下载一个学生成绩管理系统就写进简历里的半吊子。

而金宇霖，相比之下则更加专精，而且保持着一种对于计算机科学方向的敏感，在大家都在吹 Go 语言的时候，他毅然决然选择自学了 Rust ，除了竞赛用到的常规算法，他还很乐于研究一些有趣的小工具，两人以前经常在一起给二游做养成资源计算器，或者给开源项目做 PR 贡献。王悠真知道这些东西有些不足挂齿，毕竟招聘公司可不会在意它们，但也足够说明，金宇霖在计算机技术上并不逊色于他。

可是，他怎么会出现在这里。

正态分布，不是这样的！厉害的人，应该分布在最右侧才是啊！置信度的计算完全乱掉了。

更让人受打击的是，金宇霖的胸前别着的工牌，愕然写着“普通讲师”。

居然……连……高级讲师，都没有混上吗……

而且……

为什么，连希雅也在这里实习啊！

记忆里有点慵懒，穿着短裤短袖趴在活动室睡觉的希雅，现在完全被另一个人取代——她穿着有点不太合身的工装，脸上是完全不同于熬夜通宵的另一种疲惫。

“送表弟来上课吗，周末也这么努力，真是辛苦了啊。”

希雅似乎从刚才就一直在留意这边。她也是 ACM 社团的一员，ACM 社团中的“萌妹”并不算少，但要是严格地仅统计生理性别的女孩子，那就十分稀少了……

王悠真还记得他们第一次时的相遇，那时正是 ACM 社团招新的面试，王悠真则是在金宇霖一旁作为副面试官。

“你的笔试成绩还不错，不过，笔试的内容和实际上的社团生活并不一样，这一点我们之前没有说明过。”

“换而言之，这种无聊的智商检测小考试，仅仅是想把来刷德育分的同学踢出去——我们对他们并无恶意，但社团资源有限，活动室也没办法容纳那么多人。”

“如果要加入的话，到时候可能会出现“下晚自习了还要拉去集训”的地狱场景哦，现在要退出的话还来得及？”

金宇霖的表情十分严肃，但希雅却没有任何紧张，一点没有被他的气势吓住。

“没问题的！虽然我以前没有学过算法，但我会好好努力的！”

王悠真松了口气。

金宇霖在面对社团的事情上，会表现出完全不同的严肃感，或许是某种名为责任心的东西在作祟，不过，毕竟 ACM 社团也不是什么热门社团，就算有学院的扶持，每年来的人也寥寥无几，要是再这样把仅有的几个感兴趣的同学，全部都拒之门外，ACM 社团就可以考虑变卖家产，天各一方了。

况且……

要是其他社员知道，把希雅这样的女同志挡在外面，恐怕会引起众怒，到时候就算是社长的浮木，也需要在湍急的河流中上下颠簸了。

王悠真几乎能想象得出来社长的大头照被P在 1L 饮料瓶上，然后让 AI 换色成牢大同款，到时候就算是隔壁学校的 ACM 社团，也要到处转发这种抽象表情包了。

还好这一切并没有发生。

于是，希雅顺利地成为了 ACM 大家庭的一员，并且成为了活动室的常驻嘉宾。

尽管她后来去研究前端方向了，似乎是因为她本身就对美术和视觉一类的东西感兴趣，后来对算法竞赛的事情也只是浅尝辄止，但三人彼此奋斗，获得国赛金牌的事情还历历在目。

王悠真没想到，连希雅也在这里实习。

“这是在搞什么……”

王悠真小声嘟囔着。

虽然这两年前端确实有点衰落，经常被人调侃要完蛋了，但以希雅的能力，再怎么说应该也能找到一个月薪8000的 Vue 或是 React 方向的实习开发工作吧，再不济应该也能混到外包公司去。

不过，希雅似乎还不知道方才王悠真和金宇霖的谈话。

“学长！好久不见啊，算下来也有几个月了，你毕业之后上哪里了呀，前段时间我还和系里的老师问呢，你是不是校招的时候去哪个大厂了？”

王悠真不敢说出校招大失败的事实。

原本以为最差能混个 JAVA 开发，没想到校招会上挤满了人，那些企业代表似乎也没精打采的，就好像一切都是来走个过场。

收下了来自学生的简历，当天晚上就在垃圾桶里看见了，看样子人家连简历都没有翻看过——不过，那种东西也没什么看的必要，反正大家都是 AI 写的。

现在 AI 辅助大学生学习，然后辅导大学生考试，帮助大学生写论文，最后再让 AI 润色简历。老师拿到作业也是 AI 批改，企业拿到简历大多也是 AI 筛一轮，闹了半天好像只有 AI 在真正学习，要不然给人家发个学位证吧，不能忽视人工智能的努力，不然未来人工智能觉醒了，第一批就要清算这些把 AI 功劳占为己有的人。

“呃……”

希雅似乎理解了王悠真的窘迫，只好尴尬地笑笑。

“看来大家，好像，过的都不怎么样呢……”

“我也到了要找实习的时候了，不过学校安排的实习不怎么样……”

希雅叹了口气。

“我也不是完全没办法接受付费上班，但是，最起码也得是专业对口一点的工作吧？”

“在校园论坛上发了求助，历届的学长学姐一片哀嚎。那家公司就是拉大学生过去刷 KPI 指标的。”

“反正，不用付工资就能让大学生来上班，还能拿到一笔鼓励企业招实习大学生的钱，拉进来之后也没打算好好培养，每天做的内容，无非就是 Excel 或者 PDF 转 Word 这种工作。”

“校园论坛上的回复是这样说的。”

“所以……”

希雅有点不好意思地垂下头，两只食指轻轻相拍。

“少儿编程什么的，实习一个月也给好几千了……况且还管一顿午饭，和那种坑人的小公司相比，反而条件还好了不少。”

“反正，在哪里实习都学不到什么东西……我已经不指望了……”

情况，居然比想象中还要糟糕。

王悠真当时实习的时候，就听闻这家公司十分抽象，所以早早避开了。然而，他的实习也没好到哪里去，虽说确实是专业对口的工作，但真过去了也不过就是做数据库增删改查的工作，这种东西他入学没多久就会了。

企业并不打算认真培养大学生的工作能力，学校也只是把人送出去就不怎么关心了。

“所以就是这么回事……”

“我那天询问社长能不能给点内推，结果人家就推荐我来这里了。”

“每天的工作，无非就是带带小孩子，不过我资历尚浅，只能带刚入学的小孩，教一些……Windows 系统软件使用之类的东西……”

这尼玛完全就是来骗家长钱的吧！

王悠真差点没忍住说出来。

要是讲 Python ，或者 C++ ，那勉强还算回事，但是，怎么用系统画板画三角形，Ctrl + c 是什么意思，怎么快捷打字——这种东西，和编程到底哪里沾边了？

还不如学什么奥数奥语呢！

“啊，那边有家长来了，我还要给人家倒水，就拜托你先在这里等待我一下好了！”

说罢，她匆匆大跨步走开。

这，这不对吧。

难道是穿越到了什么，全世界计算机专业地位下降一百万倍，但是其他专业保持不变的世界观？

“我，我，大学学了四年的，程序设计，数据结构，算法分析，面向对象，数据库管理，操作系统，编译原理……”

“就是为了……来这种地方……”

“给王博文那种小鬼，讲怎么在记事本里打字？”

王悠真再一次瘫痪在椅子上，这次他是真的没招了。早知道不搞这些去考公考编算了……可是，眼下做这个也来不及了。

一个荒唐的念头在他脑中一闪而过。

要不然，来这里当讲师算了。

金宇霖也说了，现在还有名额。

“呃啊！这，我这是在堕落啊！”

“难道，最后只能向图灵老祖借用力量，然后干脆去做自媒体或者 Vtuber 什么的——羞涩伪娘深度讲解二叉树检索和堆排序原理，那种事情不要啊！”

在如此恍惚中崩溃着，不知不觉中就到了下课的时分。

王博文似乎并没有被少儿编程吓退——又或者这东西根本简单到没有任何学习难度。总之，他冲出教室就跑到了等待区的王悠真面前。

“哎呦老弟破防了？没事，畏惧神是正常的。”

王博文用一只手捂住脸，只从指缝中露出半个左眼，嘴里嘀咕着混合着“辛辣天森”和“八嘎”的原创日语。

“我直接抓你抬手不炸了吗？”

似乎是见王悠真没什么动机，王博文立刻切换战（犯）斗（贱）型态，一个箭步冲上去捏住王悠真的袖子——然而没有什么用，反倒是被王悠真一把提起领子，放在了一边的沙发上。

“可恶的数值怪，啥阴这都不削。”

本该到了带着表弟回家交差，然后结束一天的主线的时候，但王悠真却在心里有了点别样的滋味。

反正，闲着也是闲着，要不然真去面试一下算了……

优秀的大厂程序员，先在不知名小作坊工作一段时间，再跳槽走，这也是很常见的事情。

对，很正常的，没什么的。

“喂……小鬼。”

王博文愣了一愣，以为要挨骂了，吓得缩在了一起。

“哥我错了我刚才开玩笑的。”

“我又不吃人，我等一下去问你们老师点事，你在这里给我坐好了待着，别乱跑 OK ？”

“哥，那你手机……”

“给你玩，只准玩我的号，不准拆箱子。”

“都哥们这还说啥呢，放心好了我今天就赖在这里不走了，哥你放心去吧。”

宛如小大人一样拍着胸脯保证的，便是刚才怎么看都觉得不靠谱的王博文。

“算了，还是让希雅帮我看着点算了，喂，我再说一遍，不准拆我的箱子，听懂了？”

“包的呀，不说了我给你号上点分。”

王博文此时已经完全沉浸在游戏世界里了，这倒是方便了很多事。

给小屁孩也解释不清楚，王悠真是这样想的，简单忽悠一下，然后再去问面试的事情。

他推开了办公室的门，金宇霖正坐在工位上刷短视频。

“社长，我……”

“不必多说，懂你意思。出门右转走到头，那个是负责人办公室，你就说是去面试的。”

“到时候会问你一些问题，不过都不难，按你的水平放松回答就行。”

“老板那边我提前帮你说过了，再怎么说你也是名校计算机系毕业的，差不多走个过场，和你竞争的都是些会计专业或者土木，抱着啥都投一下心态，走投无路来这里的人。”

“好……谢谢了。”

没想都，金宇霖会说出这样的话……

可是，眼下也没有别的办法，总不能一直在家“灵活就业”吧。

等到有机会了，再跳槽离开……

王悠真敲门来到了负责人的办公室，对方是一个精致打扮的中年大叔，总感觉似乎在短视频上刷到过他。

“来面试啊，刚才小金跟我说了，你在学校呢学的也不错，能来到方舟编程啊，也是我们的荣幸。”

又是客套话……

“不过啊，这个当少儿编程，也不是什么人都能来干的，也许你代码写的不错，但是不见得就能教好小孩。对于专业技能的事情，我啥也不懂，也信得过你，你们毕竟是名校的高材生。”

本以为会问一些面试八股，没想到眼前的老板丝毫不在意——或许他也知道，所谓的少儿编程并没有什么含金量，随便抓一个大学生都能来讲。

“这种东西口说无凭，明天过来试一节课，看看表现。”

“另外关于工资的事情，我们这里的抽成是50%，带4人小班，一节课时下来就是200块，不过你刚来的话，可能给你安排的课程量比较少。”

“如果试课通过了，一天至少能有两个课时的。”

“不算节假日，如果干满最低就是八千八，中午管一顿饭。”

“怎么样，能接受吗，能接受的话我们就接着往后说。”

八千八……

这个工资对于计算机行业来说，并不算高薪。

但要是和那些给 AI 写提示词，帮忙处理 PPT 的工作相比，居然还……给的挺多？

况且工作难度也不大——反正小孩又不可能一开口就问复杂的面向对象程序实现。

还挺诱人的。但是，真的要做出违背祖宗的决定吗？

王悠真有些犹豫不决，而老板则有些不耐烦。

“没想好那就改天再来，浪费我时间。”

不管三七二十一，王悠真只好先答应下来。

“不不不，我想好了，就明天，能来的。”

“那就说定了，最后一个问题。”

老板突然微笑了起来，中年人脸上的这种表情真让人有点不舒服。

“你觉得，少儿编程的本质，到底是什么？”

突如其来的，并不是复杂晦涩的问题，王悠真本以为老板会让他当场讲解一些 Python 语法细节，或者 C++ 入门之类的。

始料未及的是，居然抛出了一个这样的问题。

“少儿编程，呃，就是，给小孩子培养信息时代的综合科学素养，提前让孩子适应未来信息科技的大环境背景，让孩子在玩中学养成自我学习的习惯与兴趣，并潜移默化地塑造编程思维和解决实际问题的能力。”

等到王悠真叽里呱啦把话全说完，他才意识到自己都说了些什么。

卧槽，这特么不是我们大一水课论文写的东西吗？

明明那东西都是豆包写的，怎么到现在还记着呢。

按道理来说早该忘完了。

更关键的是，这种一听就不靠谱的东西，说出去不就完蛋了？

不过，老板的脸色却好了不少，确切的说，看起来很得意。

“还得是名校毕业的，没得说。行了，明天下午两点左右来，有个小孩预约了试课，图形化编程 Scratch ，那种东西你应该熟悉吧，一会我让希雅把课件发给你看看。”

怀抱着不知道哪里得来的小小骄傲，王悠真就这样稀里糊涂的从办公室里走了出去，才发现希雅和金宇霖一直在一旁偷听。

“你这家伙……”

金宇霖不可置信地点点头。

“学长……你……”

连希雅也被深深震撼了。

“没想到学长居然，连那种话都说得出来……以前完全不这么觉得……”

那个，其实是豆包写的啊！

王悠真很想这样吐槽，但要是被老板听到了，到手的工作怕是要 Free 了。

能够享受着来自希雅的崇拜，这感觉也不错嘛……

那个讨厌的小鬼还在外面大喊大叫，就算是方舟编程的老师也拿他没办法。希雅只会对付笨重的铁疙瘩，但对于这种魔丸小孩真的是没辙了。辅导机构的其他老师也不想趟浑水，如果说的重了一点，害的人家父母来退课，那可就糟了。

换而言之，整个方舟编程，所洋溢的气息，都绝不是正经的学习氛围。

“压力你雷霆呢老弟给我跪下！”

“喂……小鬼……”

“老弟你什么……我去，哥……您怎么来了。”

“打完这一把。”

“打你雷霆我看你是欠收拾了！”

一把夺下王博文的手机，王悠真毫不留情地上滑删掉了后台的游戏进程。

“哥！卧槽，大优势啊，别搞……”

安静下来的王博文，此刻又有些可怜了——不过王悠真才不会同情这种小鬼。

“社长，希雅，我们就先回去了。剩下的时间，也要拜托你们了。”

嘴上如此说着，王悠真却心想：

哼，什么乱七八糟的少儿编程了！等我获得大厂 Offer ，就要和这些东西说拜拜了！跳槽吧！
