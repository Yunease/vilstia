# Python也有中年危机

插一句不知道算不算题外话的话，计算机领域有一个很有意思的现象，那便是许多看起来很新的家伙，其实意外地是老东西，搞不好已经比不少人年龄还要大了。就好比前两年在少儿编程领域大火的 Python，直至今日也是机器学习最通用的语言，可它也已经35岁了，按照程序员圈子来说，这个年龄要是还没混上主管或者项目经理，那就要考虑去卖煎饼谋生了——其实烧烤也不错，因为烧烤还可以派生出一个烤鱼或者土耳其烤肉饭的子类，也算是夜市小吃摊的“王牌专业”，从风险评估和架构设计的角度来看，这种经营模式的解耦自由，可比 JAVA 开发一路走到黑要稳当多了。

可惜王悠真似乎没有意识到，就连 Python 这种名气响亮的老前辈，如今也被质疑尚能饭否了。大约是家长和学生都对黑漆漆的终端没什么兴趣，在低龄孩子中 Python 很快就被 Scratch 优化掉了，除非是专门奔着信息竞赛去的，大多数的学生都选择了所见即所得的图形化编程，家长们也更乐意看到这种东西动起来，看着猫咪一边唱歌一边跑步，总比终端打印个圣诞树什么的要好看得多。

好吧，就算一开始就规划要走算法竞赛的学生，也大多会选择 C 或是 C++ ，Python 的热度就如同完结新番的路人女配角一样不上不下得卡在这里了，只不过新番还可能会出续作或是授权联动，Python 在有生之年是播不了第二季了（可能是因为已经出到 3.14.7 了吧）。

与王悠真一样没有认清现状的，便是此刻尴尬的在讲台上，表情僵硬的金宇霖。

“小朋友，再想一想，冒泡排序是不是，要两层嵌套呀？”

无论要如何努力，金宇霖也绝不能当着参观的家长们，直接上手修改代码。

“再仔细看一看这里，是不是一层循环负责控制索引，另一层循环要和后面的数字挨个做比较呢？”

明明只是非常简单的问题，整个冒泡排序放在自学网站的博客页，建议学习用时大约也只是半个小时左右，而眼前的小孩已经上了大半个学期的课程了。况且，冒泡排序也只是最基础，最入门的算法，原理也很简单，光是重复一遍，台下的家长都大约听懂了——或者自以为已经完全明白了。

这么简单的东西，三个数字，人脑都不需要专门排序，看一眼就知道谁大谁小了。这么简单的东西，我的孩子学不会，不就是你们老师的问题吗？

估计有不少人会这样想，东西讲的太简单，就没办法把这些人糊弄过去。

然而，这个年纪的孩子，本来就没什么抽象思维，对于他们而言可以轻易地分辨10个苹果和15个桃子哪个多，但对于这种完全抽象于实际，需要靠想象力和严谨的思维来推理的东西，就显得有些捉襟见肘了。

拜托啊你快点想起来……

金宇霖拼命祈祷着，然而，四五年级的小孩只会抬起清澈而纯真的大眼睛，冲着你眨巴眨巴。

“老师，这个，循环是什么呀？”

王悠真从没见过金宇霖这副痛不欲生的样子，而台下的家长已经开始窃窃私语了。

强忍着尴尬和紧张，金宇霖姑且也算是讲完了这堂课，向学生于家长打完招呼，就一声不吭地躲进办公室里了。

前台已经有一两个家长打算退课，对于不擅长和闹事家长打交道的希雅来说是不小的压力。

没想到就连 Python 大帝也要陨落于此了吗……少儿编程什么的……果然深不可测。

替别人惋惜的时间有些太过浪费了，紧接着就是王悠真的试课。三人被分配到了同一个办公室，这就是高中时老师所说的“一荣俱荣，一损俱损”吧。

按照常见的三局两胜制，王悠真无论如何也得把社长输掉的那把赢回来。

不过，王悠真也绝非无备而来。他在自己的电脑上提前下载了 Scratch ，简单熟悉了一下操作，便已经充满信心了。

哼，可别被这种东西看扁了啊！

王悠真如此想着。

那种拖动的积木，根本不能算得上代码，只有在文本编辑器里一个字母一个字母打出来的，抑或是用快捷键或是 Tab 自动补全的，有着优雅的缩进和分号结尾的文本，才能算得上是代码，这种拖动积木拼接起来的程序，简直就是一个大型过家家！

再说了，接下来试课的小班也只有4个学生，而且家长都没来，只要稍微露一手，比如在终端里敲一行 tree c:\ 假装是黑客在窃取机密，就能吓唬住这几个孩子了。到时候让他们来续费上课，也不过就是瓮中捉鳖罢了。

哼。

理平衣角的褶皱，对着镜子保持自信的笑容，于是王悠真便走进了试课的教室。

“哎不是老弟，你怎么来了。”

王悠真“啪”地一下关掉门退了出去。

一定是走错了地址，或者内存越界，不小心通过任意门看到了什么不该看到的东西。

然而，抬起头确认了一下，王悠真便只剩下要哭出来的表情了。

王博文不知道为什么，居然成了自己的学生。

叔叔不是早就商议好了让他直接来上课吗？怎么会……

“老弟我堵桥来你不炸了吗。”

属于儿童的柔韧性若是被用作脸上，那便是难绷指数一百分的超级鬼脸。

不行要绷住，我的饭碗……王悠真拼命维持着绷住，那脸宛如扭曲的钢板一样，僵硬又一触即发。

我不要当欧尼酱了！

然而，管你要不要绷住，总得把课试了。

王悠真仔细打量了一下剩下的三个孩子，一个是穿着蕾系服，背包侧面装着两瓶魔爪的小女孩，另一个则是身穿写着 W 字母的黑色卫衣，带着口罩的神秘小子，最后一个则是有些雌雄莫辨的小男女孩——等等，这家伙该不会先天计算机专业圣体吧？

王悠真绝对忘不掉那次比赛的经历，被一个顶着看起来人畜无害的萌萌二次元头像，穿着 JK 制服裙，一开口却是理科王声线的萌汉子一路打穿的心理阴影，简直是推土机来的。

那种人打竞赛最狠了，眼睛里只有题的有效信息，打下 include 的速度大约是实验室环境光速的 0.9999999999999999 倍（绝对不是浮点数误差！），就算全盛时期的图灵转世来打擂台赛，在规定的题目范围里也怕是要栽两个跟头。

剩下两个小孩的气场也绝非等闲之辈，况且还有表弟王博文，也算是魔丸界迄今无法抵达的癫疯。

王悠真咽下了一口唾沫，不过事已至此，也只能硬着头皮上了。

不过，来自孩子们的下马威也随之如闪电般到来。

“老师，哎，别人： Python，Scratch，Cpp。我：AI编程，Chat gpt，豆包……就很，你懂吧。”

“这个 Scratch 有点太低级了，我觉得我们应该直接学习人工智能。”

“兄弟你叽里呱啦说啥呢，那老师是我哥们，给我个面子啊OK。”

表弟似乎已经和同桌混熟了……好恐怖的社交能力。

而坐在后排的蕾系小女孩和小男女孩，似乎只是低着头，没有什么反应。

“呼，还算有两个拟人的。”

“喂喂，别以为你在课堂上我就不敢把你怎么样了，你的游戏账号还登陆在我的手机上。”

“要是不想第二天看到你的金币和点券全部变成时尚小垃圾，最好就给我老实点。”

表弟才想起自己还有把柄在人身上，只好懊恼地闭上了嘴。

“我先自我介绍一下，等下你们也要介绍一下自己，从今天开始，我们就是一个班级了。”

王悠真想起小学时，好像数学老师也是这么说的。不过那时候肯定要先在黑板上写下自己的名字，可惜现在都是投影仪和白板了。王悠真懒得做板书，在桌面新建了一个 about.md 便开始快速打下自己的信息：

王悠真 王老师

从今天开始负责 4C 小班

讲图形化编程

“接下来是你们几个了，好，就从你开始。”

无视掉疯狂举手的王博文，王悠真点起了他的同桌。

“事情开始变得有趣起来了……”

这孩子轻轻拉开口罩，本以为会看到宛如狼人一样的利齿，或者因为羞于见人而遮住的胎记——事实证明，王悠真可能是狼人杀小说或者狗血治愈小说看多了。

这货完全就是中二来的啊！！！

况且这个年纪的小孩中二到底算早熟还是幼稚，根本分辨不起来啊！

“所谓名字也不过是弱者的代号，张嘉豪……这个世界上，已经很久没有人这样称呼过我了……有趣。”

眼前的张嘉豪，或许已经完全沉浸在自己的世界观里了……

“啊，很不错啊，看起来嘉豪同学在学习方面很有自己的主见。下一位。”

“老师，我的cn是黑川莓奈，欢迎找我扩列。”

等等，cn是什么鬼。class name 类名吗？但是，类名一般也不说cn吧？要是使用这种缩写，大概会和 zh-CN 混淆，然后前端学妹就会提起大砍刀兴师问罪。

不过就这么称呼人家应该也没问题……大概和笔名什么的差不多。

即便如此也想要知道为什么介绍自己的时候要声明一个类名……

“黑川同学也是非常冷静理性啊，其实学习编程，就需要这种思维。”

“下一个，这位同学，介绍一下你自己吧？”

“大家好……我叫莲子涵，虽然没有学习过编程，但是很感兴趣，希望能和大家交朋友。”

总算是来了一个正常一点的，没准子涵真有可能成为计算机领域大神。

通常情况下判断一个人有没有计算机天赋，直接判断没有就行，这样你就有了99.999%的正确率，在置信度这方面已经完全超越一众老谋深算的老教授了。可惜，没准能返回 false 呢？

王悠真又开始幻想了。

自己成为 ACM 国际赛事青少年组的教练，然后带领莲子涵一路过关斩将拿下金奖，然后就可以借此跳槽去大厂了。

这条链路也太诡异，太诡异了吧？？！

“哥，那我呢？”

虽然让这个小鬼起来介绍自己会让人很不爽，但是，考虑到小孩子之间的社交什么的，还是要给表弟一个展示自己的机会。

“OK 啊孩子们，我是王博文，这老师是我哥们，大家不用太紧张，虽然这老弟大学毕业到现在也没找到工作，但是我爸说他很厉害的。”

“不过，也仅局限在编程了，打火影忍者，这哥们其实也没什么实力。是不老弟？”

可恶……

若不是试课，恐怕现在表弟的屁股已经开花了。

隐忍……

王悠真只好忍住怒气，为了饭碗以及跳槽的机会，先就不跟小屁孩计较了！

四人介绍完毕，王悠真对学生们也有了大概的了解，只要能搞定嘉豪和表弟，剩下两个还是蛮听话的。

对付嘉豪嘛……呵呵。

这一招可是当年王悠真最豪气的时候，为了给高中的同学露两手而特意学的。尽管这些东西对于稍微懂一点命令行的人来说无异于来搞笑的，但是对付这种连电脑都没怎么摸过的人，就显得绰绰有余了。

看好了——

王悠真流利地按下 Win + R 快捷键，在唤出的窗口中敲下 cmd，紧接着立刻打下 tree c:/

这行命令其实只是树状展开文件夹目录，因为选了一个很底层的路径，会展开所有子代文件夹。

在视觉上来说，就是漆黑的命令行框中，在以惊人的速度飞速刷新着绿色的文字，一直要持续十几秒，虽然里面时不时会闪出一些中文路径名，看起来就没那么高深莫测了，不过因为刷新速度很快，台下的小孩们似乎并没有看清。

此乃 奥义·黑客数据流 之术！

黑川莓奈的脸上似乎有点点不屑，不过，这种情绪并没有太过明显地表露出来，略有些得意的王悠真完全没有发现。

与之截然不同的，便是早已目瞪口呆的张嘉豪。

小样，跟我斗，你王哥哥打 Hello World 的时候，你小子不知道还在哪里玩泥巴呢。王悠真内心里忍不住轻哼起来。

“只要你们认真学习，像这种东西，到时候你们也能做出来。”

“不过，也不要太得意忘形了，我们还是要先按照课件的内容来讲课——也就是图形化编程 Scratch ，网上也叫它编程猫，这个小吉祥物是不是还挺可爱的？”

把最头疼的两个熊孩子镇住以后，问题也算解决了大半。

表弟虽然很惹人生气，不过，正式开始上课后，也意外的十分认真。

看起来，这些孩子表现还不错嘛——按这个架势，试课通过也是显然的了。

第一节课的内容十分简单，无非就是些认识 UI 和基础积木的事情，这让王悠真依稀回忆起最开始写 C 语言的时光，不过，他还是坚持认为，只有用键盘打出来的才算代码，那种积木拼装的东西，根本就是玩具。

“总之……今天就是这么多。”

按照授课规划，现在应该还要提问几个问题。

不过，王悠真耍了一个小小的心机，如果提的问题太过困难，没准小孩下节课就不来了——到时候不得还亏点工资。既然没有监察机制，王悠真索性就忽略掉了这个环节。

“老师再见——”

几个孩子如此说着，于是开始关闭电脑，然后出去——这么老实怎么可能！

张嘉豪不知道抽了什么风，直接倒在地上——坏了！教师资格证正在缓缓消散——等等，王悠真好像压根就没考这种东西。

王博文似乎是被吓到了，他探着脖子，似乎是在考虑到底要不要上前帮忙。

可是，王悠真仔细观察着，却发现这个孩子并非真的突发恶疾，而是一种名为中二的病发作了。

张嘉豪的嘴里小声念叨着什么。

“十年前的仇……你难道忘记了吗……”

全然搞不懂发生了什么的几人，只好就这样愣在原地。

“老弟别怕，我来给你做人工呼吸了！”

王博文像是鼓起了很大勇气，他深吸了一口气，然后缓缓蹲下——

“卧槽别过来。”

张嘉豪被眼前一幕吓一大跳，连忙爬起身后退几步，似乎还心有余悸。

“牛逼不牛逼，也是治好了好吧。”

王博文似乎早就料到了这一切，而张嘉豪像是泄气了一般，这场较量算是分出胜负了。当然，王悠真不会在乎这些，只要别真似在我课堂上就行，不然到时候可就完蛋了。

结束这场小小闹剧，让王悠真稍微有些在意的，便是离开教室后，一直坐在休息区看书的莲子涵。

这家伙的父母不来接吗？

虽然，五年级的小孩子，就算一个人回家也没太大问题，不过他一直坐在这里，大约是和父母约定好了吧。王悠真也只是有一点点在意，只要确认学生没什么大碍，那便是人家的私事了。

方舟编程培训中心的负责人对王悠真的表现十分满意，没有太多手续便签写了合同，现在王悠真总算是摆脱了“灵活就业”的帽子，可喜可贺，可喜可贺。

“为了庆祝学长找到工作~”

“咱们三个，一起去吃烤肉吧，学长，这次轮到你请客了！”

洋溢着灿烂笑容的少女，似乎在前台等待王悠真好长时间了。倒也不是非要蹭这一顿饭，况且希雅平时胃口很小，多数时候，三人都是挤在集训教室里，一起讨论某个算法题的优化策略。

或许只是单纯的，想要小小的聚一下吧……

自从社长离开 ACM 社团，也足足有一年多了。

在这一年多的时间里，王悠真因为要准备毕业论文，所以倒没太多特别的心情，他已经完全接受了每个人都应该有自己的事情，有自己要单独去面对的东西，相逢便是缘分，离别也仅仅是中断了某一个进程，或许改日还得相见。

但是，希雅却绝非如此。

ACM 社团对于每个社员来说，都是如同家一样的地方，尽管多数社员早已经放弃了算法竞赛，但活动室沙发上敞开的零食，还有隔壁硬件社团的用于“外交”而赠送的小机器人，都早就默默在心底给他们留下了某种归属感。

ACM 社团和学生会那种地方完全不一样，每个人都很珍惜这里。只可惜因为社团实在是没什么名气，加上金宇霖非常严苛的入团考试，导致近几年加入的社员，反而是越来越少了。

对于希雅这种连同班同学都认不齐的人来说，ACM 社团就并不是可以如此轻易割舍的东西，每一个绩点或许不高的社员，都是大学里十分珍贵的朋友。

或许正因如此，她才如此重视这一切。

即便已经出去实习，即便社长也早就换人，但是，最舍不得 ACM 社团的人，恐怕还是希雅吧。

——真是奇怪呢。

明明社长和另一个社团的核心社员都已经接受了这种离别。

王悠真并不介意请大家吃饭，况且虽然说是请客，但社长和希雅都不是那种在请客时，会为难人的家伙。

上次大家在一起，都是一年多以前的时光了，彼时的金宇霖才从学校毕业。

新的社长选给了另一个活动室的常驻嘉宾，其实金宇霖是想让位给王悠真或者希雅的，可惜王悠真要也要忙着毕业的事情，只能推脱掉了。

而那时的希雅，只是轻轻拒绝，没有再说什么多余的话。

新社长依然受到大家的喜欢，甚至来年的时候，入社的社员居然突破性地超过了5人。

不过，对于希雅来说，那种感觉也完全不一样吧……

“虽然这么说很抱歉……”

“等会儿我要开个会……唉，上午那个班讲冒泡排序有点糟糕，现在退课的家长很多。”

金宇霖苦笑了一声。

“看样子这学期我评不上高级讲师了，不过，你们也别灰心，现在学 Python 的学生越来越少了，没准这次开会就是商量要取消、或是缩减开设这门课程。”

“这样啊……”

原来如此……

即便如此还是很难接受。没想到大学时被王悠真吐槽过很多次缩进语法反人类的 Python ，现在也混的不太好了。

他有种莫名其妙的同病相怜，但仔细想想又好像是太自作多情了，少儿编程这种市场能有多大，Python 以后还是会继续用在机器学习上的，而且未来的工具脚本，大约也会是 Python 更多吧。

“那，学长，咱们就简单吃点东西吧，聚餐的事情等过两天社长忙完了再说？”

几乎是带着些恳求的，希雅又转头注视着王悠真。

“楼下有家砂锅米线，就连方舟编程的老板也经常吃，味道没得说。”

“虽然我今天没办法来了，不过你们可以试试这家——话说回来，希雅你还没尝过吧？”

“啊，好像是这样没错。”

告别了社长，王悠真和希雅并排一起下楼。

尽管现在才是傍晚，但方舟编程机构已经十分冷清了，与之完全不同的是，楼下的夜市小摊才逐渐开始开张，但要是等到道路两边都开满各种烤肠或是煎饼摊，大概还需要一两个小时。

王悠真要了一份加鱼丸的经典过桥米线，而希雅则是点了麻辣烫套餐组。

“作弊啊！有这么划算的套餐，早知道我也不吃这个了！”

大概方舟编程的老板，吃的也不是这份过桥米线，否则大概不会成为回头客了。王悠真心底里小声吐槽着，倒也不算难吃，只是这味道未免也太淡。

希雅忍俊不禁地笑出了声。

“明明都写在最显眼的地方了，不过下次的话可以试试干拌麻辣烫，味道也很不错哦？”

能够泰然自若地说出这样的话，看样子希雅也没少在这里吃。

似乎是因为金宇霖不在，希雅最终还是选择什么也没有说。对于精修前端方向的人来说，想必很清楚消息队列的顺序重要性和异步问题的转换吧。

等一下，这种时候，怎么还有小学生一个人在这种地方吃饭。

倒不是说这家店不怎么样什么的，只是这里相对远离住宅区，怎么看都不像小学生会出没的地段。

“那个，你怎么一个人在这里。”

王悠真努力让自己的语气不像奇怪的大叔，不过好像感觉更奇怪了。

“老师？”

眼前的小孩转过头来，王悠真才认出来是自己的学生莲子涵。

“这也不早了，你的父母不来接你回家吗？”

莲子涵低着头，似乎一直在盯着碗里的小青菜，这是在挑食吗？

他的书包看起来有点旧，四年级的孩子，大约也到了该换书包的年纪了吧？

“我吃完了，谢谢老师，家里人还在等我。”

莲子涵摇摇头，然后走了出去。

目睹此景，王悠真也不好多说什么，况且两人也只不过是刚刚认识的程度。

作为课外班的授课老师，王悠真并不需要想学校老师那样负责，也不需要操心学生在学习以外的事情。

不过，希雅似乎完全没有被这一切干扰到。

“学长……前端好像真的要完蛋了。”

“我以为啃完了 Vue ，做一两个响应式网站，就能找到一份还行的实习工作了，毕竟身边的同学，大多还停留在原生的 HTML 。”

“没曾想……现在都要求全栈开发，我勉强能写一点点 Node js，不过涉及到具体的后端管理，就完全没有经验了。”

“我也没好到哪里去……”

曾几何时，JAVA 还是如明星般闪耀的语言，号称 一次编译，到处运行，靠着如同外挂一般的兼容性横扫了企业市场，当年甚至连哲学专业的人都跨行来学 JAVA 开发。

现在呢……

“之前有一个给 AI 写提示词的工作，不过我最后还是没去。”

言外之意是，王悠真有点看不起那种东西，这种小小的固执，其实希雅也完全感同身受。

“我以为前端是是充满设计艺术和人文交互的东西……”

“不过，怎么看都感觉像是非常臃肿的 npm 包在疯狂堆积。”

说到这时，两人同时愣住，一个单词几乎同时出现在两人脑中。

生成式通用人工智能大模型——也就是 AI。

大学时的“老师”最终还是抢了自己的饭碗，这倒是有点讽刺了。

“唉。”

希雅与王悠真同时叹气道。

“所以……我居然还觉得，在方舟编程给小学生上课，意外的还不错……”

真的……不错吗？倒不如说，是压根没得选吧。这样想来，其实没有什么区别就是了。

“学长，你觉得呢？”

希雅突然抛出问题来，她似乎是犹豫许久，才下定决心要问出一样的。

——当然是，借此先掌握行业的最新动向，积累工作经验，然后筹备个人作品集，最后跳槽去理想中大厂的 JAVA 后端开发岗。

王悠真本想这样说。

“还……不错吧，起码是挺轻松的。”

像是得到了预期中最没有价值的答案似的，希雅有些丧气，或许这种问题，连王悠真本人也没有搞明白吧。

如今还在徘徊的人儿还不清楚，恐怕也没必要清醒。

“看来学长也觉得不错呢，那就好。”

AI 在悄无声息中夺走的，从来不是工作，而是他们相信未来的方式。

而他们失去的，也不仅仅是某一份特定的工作，而是一直以来的，对于计算机所怀揣的一切憧憬。

只不过现在，王悠真和希雅都没有弄明白这一点。
